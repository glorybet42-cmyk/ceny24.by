# Ceny 24.by — маркетплейс запросов для автозапчастей и стройматериалов

**«Умный посредник» между покупателями и продавцами в Беларуси и России.**  
Сервис автоматизирует поиск поставщиков: вместо обзвона десятков компаний покупатель публикует одну заявку, а продавцы получают целевые запросы в реальном времени.

---

## 🚀 Главное преимущество — модель «аукциона наоборот»

| Традиционные площадки | Ceny 24.by |
|----------------------|------------|
| Покупатель сам ищет товары и обзванивает продавцов | Покупатель описывает **что ищет** — продавцы сами приходят с предложениями |
| Продавцы пассивно ждут, пока их найдут | Продавцы получают **горячие заявки** от покупателей в их городе и категории |
| Цены могут быть завышены из-за отсутствия конкуренции | **Эффект аукциона**: продавцы не видят предложений друг друга и вынуждены давать лучшую цену |
| Множество площадок, на каждой нужно регистрироваться и мониторить | **Единый центр**: одна регистрация, все заявки в одном окне, включая чат и историю |

> **Уникальность**: сервис не продаёт товары, а **соединяет потребность покупателя с предложением продавца** в конкретном городе и категории. Это снижает время поиска с часов до минут и повышает конверсию запросов в продажи.

---

## 🎯 Для кого

- **Покупатели**: ищут запчасти, стройматериалы, инструмент — получают актуальные предложения от всех продавцов в городе за 2–3 минуты.
- **Продавцы**: получают целевые заявки от реальных клиентов без холодных звонков и рекламы.
- **Администраторы**: верифицируют продавцов через ЕГР, управляют пользователями и получают уведомления о новых регистрациях.

## 🛠 Технический стек и архитектура

| Уровень | Технологии |
|---------|-----------|
| **Backend** | Python 3.13, Flask, Flask-SocketIO, Celery, Redis |
| **Frontend** | Jinja2, Vanilla JS, Choices.js, Toastr, Service Worker (Push API) |
| **Database** | PostgreSQL, psycopg2 (прямые SQL-запросы, без ORM) |
| **Async** | Celery + Redis (отправка email, push-уведомлений) |
| **Auth** | Flask-Login (сессии), Flask-JWT-Extended (API), bcrypt |
| **Push** | Web Push API (VAPID), Service Worker для браузерных уведомлений |
| **Email** | Gmail SMTP (TLS), кастомный EmailService с HTML-шаблонами |
| **Security** | CSRF-защита (Flask-WTF), rate limiting (Flask-Limiter), CSP-заголовки |

### 🧩 Ключевые модули
- **Мульти-ролевая система**: покупатель, продавец, администратор с раздельными интерфейсами.
- **Кастомный мультиселект** для категорий и подкатегорий товаров (Беларусь/Россия).
- **Гео-привязка**: динамическая загрузка регионов и городов через API.
- **Система рейтинга и отзывов**: покупатели оценивают продавцов после сделки.
- **Верификация продавцов**: проверка регистрационных номеров через открытые реестры (ЕГР), ручная активация администратором.
- **Админ-панель**: дашборд, управление пользователями, проверка продавцов, уведомления в реальном времени.
