# Ceny24.by — двусторонний маркетплейс

**Ceny24.by** — это «умный посредник» между покупателями и продавцами в Беларуси и России.  
Покупатель размещает одну заявку на автозапчасти или стройматериалы, а продавцы в его городе получают целевой запрос в реальном времени и конкурируют за лучшую цену (продавцы не видят предложений друг друга).

## Возможности

- Геопоиск по городам
- Чат между покупателем и продавцом
- Push-уведомления
- Слепые аукционы
- Регистрация и аутентификация
- Личный кабинет

## Технологии

- Python 3.13
- Flask
- Flask-SocketIO (WebSockets)
- PostgreSQL
- Celery + Redis
- Jinja2
- Vanilla JS
- Web Push API
- Docker, CI/CD
